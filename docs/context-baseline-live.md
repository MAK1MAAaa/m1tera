# ChatGPT 首轮上下文实测

已通过独立的 ChatGPT 授权，在 macOS arm64 桌面应用中调用 `gpt-6.1-sol`。0/4/20 个工具定义的成功请求分别返回 **49 / 237 / 957** 个输入 tokens。结果来自两轮测量中的成功请求，不能视为一轮全部成功或稳定性测试。

固定用户消息：`只回复 OK，不调用工具。`。每个案例使用空历史、同一个默认系统提示词和同一个模型。20 个工具是四个基础工具 schema 的合成扩展；基线仅发送定义，不执行工具。

全部成功样本的缓存读取和缓存写入均为 0。服务商未提供系统、工具、历史的精确分项 usage；表中分项属于本地 `o200k_base` 对实际请求结构的保守估算。它们不能替代模型的 tokenizer 或服务商总计数。工具定义带来的实测增量为 188 / 908 tokens，针对当前 schema 和短消息，不能推广到任意工具。

默认策略继续采用零工具、显式系统提示词和可见的上下文估算。本轮不据这些少量样本设置硬 token 上限。用户按会话启用工具，后续可根据自己的工具、长历史和任务分布决定预算与摘要策略。
