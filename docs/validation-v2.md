# 0.2.0 验证记录

验证日期：2026-10-12。目标环境：macOS arm64。轻量化的目标是模型上下文优化，桌面能力与安装包体积不作为裁剪目标。

本轮把会话与工作区组织从模型上下文中分离：工作区和分类单独存储，置顶、名称、归属和审批模式存于会话元数据；模型请求只包含显式提示词、消息历史和当前启用的工具。创建个人会话保持空工作区、零工具、逐次审批；手动改名不会被下一轮消息覆盖。

[暗色截图](screenshots/desktop-dark-model-picker-fixture.png)来自真实 React 布局与 CSS，模型目录和登录状态使用隔离测试 fixture。浏览器 E2E 不替代真实服务商验收。0.1.0 的 ChatGPT 真实聊天、工具及 0/4/20 基线结果保留在 [历史验证记录](validation.md)与 [基线报告](context-baseline-live.md)，本轮没有重复采集新的真实 usage，也没有自动授权新的账户访问。

最终打包应用已实际启动，旧的三条会话成功恢复。通过原生界面筛选到实际目录的 `gpt-6.1-sol`；将此前的空测试会话改名为“桌面功能验证”；原生目录选择器添加 `tests/fixtures/workspace`，并在其中创建零工具会话。全过程没有调用 write_file、run_command 或真实模型接口。最终 app 中 16 个运行时编译文件与当前 `dist-runtime` 逐文件散列一致，内置依赖清单与最新 lockfile 散列一致。

自动审批仅批准当前会话已启用工具的写入和命令，策略在运行开始时冻结；运行中取消仍有效，文件真实路径检查保持。批准的 shell 仍具有当前用户权限，工作目录不构成 OS 沙箱。自动批准发送明确执行事件，界面显示“自动批准”；没有保存或读取 Codex 的凭据。

OpenDesign 参考明确展示演示状态，实际应用直接实现同一信息结构。预览服务仅绑定本机，服务目录是静态设计文件的临时导出，避免暴露整个源码目录。设计规范与参考位于 `opendesign/`。

其他操作系统、独立无 Node 机器安装及公开签名/公证仍未验收。当前凭据只存内存，应用升级重启后需要重新授权。产物散列和内置运行时一致性记录见 [产物清单](release-artifacts.json)。
